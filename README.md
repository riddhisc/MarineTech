# Marine Tech Control Services

Website for [marinetech.co.in](https://marinetech.co.in), hosted on GitHub Pages.

## Pages
`index.html`, `services.html`, `products.html`, `stockiest.html`, `contact.html`

## Contact form
The form on `contact.html` sends messages through [Web3Forms](https://web3forms.com) to purchase@marinetech.co.in. The access key is set in the form's `access_key` field. It is a public key, so it is safe to keep in the page. To change where messages go, create a new key at web3forms.com with the new email address and replace the old key in `contact.html`.

## Notes
Keep the `CNAME` file. It is what ties the site to the custom domain.
